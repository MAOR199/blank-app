# AI Learning Lab — גרסת MVP

מערכת Streamlit לניסוי השוואתי בין שימוש חופשי ב-AI (קבוצה A) לבין סוכן פדגוגי מובנה (קבוצה B). כוללת הסכמה, שאלון מקדים, צ'אט, הגשת תוצר, שאלון סיום, לוגים ושאיבת CSV/Excel. כל משתתף מקבל מזהה אקראי וקוד חזרה חד־פעמי. **זוהי גרסה ניסיונית, לא מערכת מחקר מוכנה להפעלה ללא אישורים ובדיקות.**

## לפני הכול

- אין להשתמש במשתתפי מחקר אמיתיים עד לקבלת אישור אתיקה, הסכמה מדעת מתאימה, הגדרת אחסון ומדיניות מחיקה, ובדיקת ספקי השירות.
- מטלת הדוגמה והשאלונים אינם מאומתים — החליפו אותם לפני ניסוי אמיתי.
- הנתונים **מקודדים ולא אנונימיים לחלוטין**: תוכן חופשי בצ'אט עלול להכיל מידע מזהה. תוכן השיחות נשלח למודל Groq ועובר דרך ספק האירוח; ראו הסכמי ספקים ונהלי פרטיות.
- המודל זהה בשני התנאים (`GROQ_MODEL`), ההבדל הוא בהנחיות `SYSTEM_A` / `SYSTEM_B`.
- הפיילוט לא תוכנן לעומסים גבוהים. יש לבצע בדיקת עומסים לפני שיעור רב-משתתפים.
- תשלום: Streamlit Community Cloud מציע תוכנית חינמית בכפוף למגבלות. Supabase ו-Groq עשויים לכלול מכסות/עלויות. בדקו את המצב העדכני בחשבונותיכם.

## שלב 1 — GitHub

1. צור/י מאגר GitHub חדש, מומלץ **Private**, בשם `ai-learning-lab`.
2. העלה/י את הקבצים `app.py`, `schema.sql`, `requirements.txt`, `.gitignore` ואת התיקייה `.streamlit` עם `config.toml`.
3. אין להעלות **לעולם** את קובץ הסודות האמיתי, מפתחות API או קובצי נתונים. `secrets.example.toml` הוא תבנית ללא סודות.

## שלב 2 — Supabase

1. היכנסו ל-https://supabase.com וצרו פרויקט חדש (אחסון ענן).
2. עברו אל SQL Editor, העתיקו את תוכן `schema.sql` והריצו אותו פעם אחת.
3. ב-Project Settings / API (המיקום עשוי להשתנות) מצאו `Project URL` ואת **service_role / secret key** בצד השרת.
4. **זהו מפתח בעל הרשאות גבוהות.** אין לשתף אותו, להדביק אותו בצ'אט ציבורי או לשמור אותו ב-GitHub. יש לשמור אותו ב-Streamlit Secrets בלבד. אין להטמיע אותו ב-JavaScript בדפדפן.
5. הפתרון הזה הוא MVP לשרת Streamlit אמין יחיד. לקראת ניסוי מלא יש לשקול מדיניות הרשאות קפדנית יותר ובידוד שירות נתונים.

## שלב 3 — ספק AI

1. צרו חשבון ב-https://console.groq.com וצרו מפתח API.
2. בדקו בחשבון שלכם איזה מודל זמין ומה מגבלות השימוש. ערך ברירת המחדל הוא `llama-3.3-70b-versatile`, והוא עשוי להשתנות.
3. שמרו את המפתח ב-Secrets של Streamlit, ולא במאגר הקוד.

## שלב 4 — פריסה ל-Streamlit

1. פתחו https://share.streamlit.io ובחרו **Create app**.
2. בחרו **Yup, I have an app**.
3. בחרו את מאגר GitHub ואת ענף `main`, והקלידו `app.py` כנתיב הקובץ הראשי.
4. פתחו **Advanced settings → Secrets** והזינו את הערכים מתוך `secrets.example.toml` עם הסודות האמיתיים (ללא שיתוף שלהם במקומות אחרים).
5. צרו `GROUP_A_TOKEN` ו-`GROUP_B_TOKEN` שונים וארוכים, למשל בעזרת `python -c "import secrets; print(secrets.token_urlsafe(32))"` פעמיים.
6. הגדירו בהתחלה `EXPERIMENT_ENABLED = false` — דף הניהול עדיין נגיש, אך כניסת משתתפים חסומה. לאחר הכנה ואישור הפיילוט, הגדירו `true`.
7. לחצו **Deploy**. אם שיניתם Secrets לאחר הפריסה, הפעילו מחדש לפי הצורך.

## שלב 5 — קישורים

החליפו `YOUR-APP` בכתובת האמיתית שלכם ו-`TOKEN_A` / `TOKEN_B` בערכים שהגדרתם:

- קבוצה A: `https://YOUR-APP.streamlit.app/?invite=TOKEN_A`
- קבוצה B: `https://YOUR-APP.streamlit.app/?invite=TOKEN_B`
- חוקר: `https://YOUR-APP.streamlit.app/?admin=1`

הקישורים לקבוצות הם קישורי הזמנה משותפים, **לא אימות אישי ולא הבטחה שלא יעבירו אותם לאחרים**. לשימוש אמיתי רצוי לייצר אסימון חד-פעמי נפרד לכל משתתף ולהקצות קבוצה מראש.

## בדיקת פיילוט (עם נתוני דמה בלבד)

1. אחרי הגדרת `EXPERIMENT_ENABLED = true`, פתחו את קישור קבוצה A בחלון גלישה פרטי.
2. אשרו את נוסח ההסכמה כדמות בדיקה, שמרו את קוד החזרה, מלאו את השאלון.
3. שלחו הודעה בצ'אט, וודאו שתשובת AI מתקבלת, הגישו תשובה ומלאו שאלון סיום.
4. חזרו על אותם שלבים בקבוצה B, בדקו התקדמות בששת השלבים.
5. פתחו את קישור החוקר עם סיסמה: בדקו שקיימות רשומות בחמש הטבלאות ושהורדת CSV/Excel עובדת.
6. רעננו את דף המשתתף ושחזרו בעזרת קוד החזרה. בדקו שפעילות קודמת נשמרה.
7. הסירו רשומות הדגמה לפני תחילת ניסוי אמיתי, אם אושר.

## מגבלות מהותיות של גרסה זו

- אין עדיין מערכת הזמנות אישיות, ביטול הסכמה אוטומטי או מנגנון מחיקה עצמית למשתתפים. אין להציג יכולות אלה כפעילות.
- סטטוס הקבוצה מבוסס על קישור משותף; מי שמשיג את שני הקישורים עשוי להיכנס לשניהם. נדרשת הקצאה מבוקרת לניסוי מדעי.
- המנגנון של שלבי קבוצה B מתקדם דרך כפתור ולא דרך הערכה מדעית של השלמת השלב.
- שאלוני לפני/אחרי אינם סולמות מאומתים; אין מדידת ביצועים אוטומטית במחוון.
- זמן פעילות איננו נמדד כזמן למידה פעיל; נשמרות חותמות זמן ומשך זמן תגובות API.
- אין כרגע בדיקות עומס, ייצוא מדדים מחושבים או סינון אנונימיזציה של טקסט חופשי.
- תמלילים מועברים לספק מודל חיצוני, שעלולות לחול עליו מגבלות גאוגרפיות/חוזיות.
- לא מומלץ לפרסם ברבים קישורי הזמנה או קישור חוקר. הגבלת כניסה לחוקר מבוססת סיסמה אחת לצורכי MVP בלבד.

## הרצה מקומית (אופציונלי)

```bash
pip install -r requirements.txt
mkdir -p .streamlit
# Copy secrets.example.toml to .streamlit/secrets.toml and fill in values
streamlit run app.py
```

אישור אתיקה ופרטיות; הקצאה אישית מבוקרת; שאלוני מדידה מאומתים; מטלת מחקר אחידה ומחוון; מערכת מחיקה ותיעוד משיכת הסכמה; מדידת זמן תקפה; ניטור כשלים; בדיקות ריבוי משתמשים; הקשחת הרשאות חוקר; ניהול גרסאות ניסוי וניתוח נתונים.
